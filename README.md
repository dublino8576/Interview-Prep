# Interview Prep

This repository contains my preparation for Junior Software Engineer interviews. It includes common technical and behavioural interview questions, together with my personalised answers, notes, and examples from my own projects and experience. The goal is to strengthen my technical communication, reflect on past work, and prepare concise, structured responses for interviews.
